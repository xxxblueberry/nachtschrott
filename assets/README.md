# Workshop menu background

`menu-workshop.webp` is an original AI-generated workshop scene created for
Nachtschrott's approved dark industrial main-menu design. It contains no text,
UI, or character artwork. The game renders its existing animated heroes on top.

Keep this file with `index.html` when deploying. The service worker precaches it
for offline use. The desktop layout uses a single cover image; portrait uses the
existing compact menu. The bench surface is anchored at 78% of the image height.
